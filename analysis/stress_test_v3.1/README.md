# Stress test of v3.1

This folder is a stress test of the published v3.1 mid-band model.
Predictions were written to `00_predictions.md` at 10:48 Asia/Calcutta
(05:18 UTC) on 13 November 2026, before any new model run. No v3.1
default was changed.

- Engine: `run_v31.py` (run once; outputs in `outputs/`).
- PDF builder: `build_pdf.py`. The shareable PDF is
  `docs/stress_test_v3.1.pdf` and `/workspace/stress_test_v3.1.pdf`.
- Task 0, Task 7, the prediction score, brief problems, and the
  proposed v3.2 change list are the numbered markdown files in this
  folder.

Call it a stress test, not a hostile review. Task 6 (price bands,
SKU curves, new categories) is v3.2 work and is kept out of the
v3.1 verdict tables.
